# NeuroCare 🧠

NeuroCare is an AI-powered healthcare web system designed to assist in early detection, monitoring, and management of neurological and lifestyle-related health conditions. The platform integrates machine learning, predictive analytics, and modern web technologies to provide intelligent health insights, virtual assistance, and personalized care plans.

---

## 🚀 Features

* **User Profile Management**
  Secure user registration, authentication, and profile handling.

* **Alzheimer’s Disease Detection**
  AI-based analysis to assess the likelihood of Alzheimer’s disease using patient data.

* **Brain Stroke Prediction**
  Machine learning models to predict stroke risk based on medical parameters.

* **Virtual Doctor Assistance**
  AI-powered virtual doctor for preliminary consultation and health guidance.

* **Lifestyle & Health Plans**
  Personalized lifestyle recommendations including diet, exercise, and daily routines.

* **Push Notifications**
  Timely alerts for health reminders, reports, and updates.

* **Payment Gateway Integration**
  Secure online payments for premium features and consultations.

* **Statistical Analytics Dashboard**
  Interactive analytics and visualizations for health trends and predictions.

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/neurocare.git
   ```

2. Navigate to the project directory:

   ```bash
   cd neurocare
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   ```
   http://localhost:5000
   ```
